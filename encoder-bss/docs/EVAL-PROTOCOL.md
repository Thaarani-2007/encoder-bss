# Evaluation protocol

## Splits (`eval/acsim_tierb` or `eval/acsim_clean`)

| Split | Speakers | Static noise | Events | Reverb |
|-------|----------|--------------|--------|--------|
| **D-All** | 2 | yes | yes | yes |
| D-NE | 2 | yes | yes | no |
| D-NR | 2 | yes | no | yes |
| D-N | 2 | yes | no | no |
| S-All | 1 | yes | yes | yes |
| S-NE / S-NR / S-N | 1 | (same pattern) | | |

Generated by `scripts/generate_eval_sets.py` using `ACSIMSimulator` (`src/bss_audio/data/acsim/simulator.py`).

## Metrics (`metric_profile: train`)

- **si_sdri:** PIT-aware SI-SDR improvement vs mixture (two-speaker splits).
- **si_sdr_mix_db:** SI-SDR of using **mixture as both outputs** (constant w.r.t. model; baseline).
- **si_sdr_est_db:** SI-SDR of model estimates.
- **silence_sdri:** single-speaker splits only.

Full profile adds PESQ, ESTOI, mir_eval SDR (CPU-heavy).

## Primary score

`primary_score()` = **D-All** `si_sdri` only. Early stopping and checkpoint selection use this unless configured otherwise.

## Clip counts

| Label | Meaning |
|-------|---------|
| **50 clips** | `eval.max_clips_per_split: 50` — matches historical Phase 1b in-loop training |
| **225 clips** | Full split on disk — use for publication-style reporting |

Always report **eval root**, **clip count**, and **profile** next to any dB number.
